============================================================
REWARD FUNCTION (Same for All Models)
============================================================
All models use the same UnoEnv environment with this reward structure:

| Event                              | Reward                              |
|------------------------------------|-------------------------------------|
| Win the game                       | +100                                |
| Lose the game                      | -50                                 |
| Play a valid card                  | +1.0                                |
| Play special card (SKI, REV)       | +1.0 bonus                          |
| Play +2 card (PL2)                 | +1.0 bonus + opponent draws 2       |
| Play +4 card (PL4)                 | +2.0 bonus + opponent draws 4       |
| Draw a card (no valid play)        | -0.5                                |
| Invalid action (corrected)         | -0.2                                |
| Truncation (max 500 steps)         | (opponent_cards - player_cards) × 2 |
